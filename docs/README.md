## Reading results / 阅读结果

Read the data origin, checkpoint and decision coverage together. A `controlled` experiment remains blocked from operational effectiveness claims. An integrity check does not certify a producer, and a passing core type gate does not clear historical type debt.

阅读结果时同时查看数据来源、检查点与决策覆盖率。`controlled` 受控实验不能被视为生产有效性证明；完整性校验不是来源认证，新核心类型检查通过也不等于历史类型债务清零。
